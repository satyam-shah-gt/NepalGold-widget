# App icon — provenance and usage rights

The launcher icon (`ic_launcher_foreground`) was **generated for this project** with an
AI image generator and then prepared for Android adaptive icons. It is original artwork:

- It does **not** reproduce, trace or adapt any existing gold exchange's logo, emblem or word
  mark, and it contains no third-party trademark.
- The artwork is therefore free to use, modify and redistribute - including commercially - with
  no attribution requirement and no licensing fee.
- It is not registered as a trademark, so nothing here grants trademark rights. If the app is
  published under a brand name, consider registering the mark separately in the markets you
  target.

## Files

| File | Role |
|---|---|
| `res/mipmap-anydpi-v26/ic_launcher.xml` | Adaptive icon (background + foreground + monochrome) |
| `res/mipmap-anydpi-v26/ic_launcher_round.xml` | Round variant of the same adaptive icon |
| `res/mipmap-*/ic_launcher_foreground.webp` | The logo artwork, one file per density |
| `res/drawable/ic_launcher_background.xml` | Charcoal gradient behind the logo |
| `res/drawable/ic_launcher_monochrome.xml` | Hand-drawn silhouette for Android 13+ themed icons |

`minSdk` is 26, so the adaptive icon covers every supported device and no legacy PNG launcher
icons are needed.
